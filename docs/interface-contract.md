# Контракт программного интерфейса

## 1. Выбор интерфейса и связь с требованиями

* **Связанный пользовательский сценарий:** US-4. Создание темы (соответствует функциональному требованию **FR-4** — «Создание и редактирование тем»).
* **Компонент / Модуль:** Модуль работы с форумом и темами (`flaskbb/forum/views.py` и `flaskbb/forum/forms.py`).
* **Назначение операции:** Обработка HTTP POST-запроса от авторизованного пользователя для создания новой темы обсуждения в заданном разделе форума.

---

## 2. Описание контракта

### 2.1. Способ вызова и инициатор
* **Инициатор:** Зарегистрированный пользователь (или Администратор/Модератор) через веб-интерфейс браузера.
* **HTTP-метод:** `POST`
* **Маршрут (URL):** `/forum/<int:forum_id>/topic/new` (где `forum_id` — уникальный идентификатор форума в базе данных).

### 2.2. Входные данные (Параметры запроса)
Данные передаются в теле HTTP-запроса в формате `application/x-www-form-urlencoded` (данные HTML-формы `NewTopicForm`):

| Параметр | Тип | Обязательное | Описание и допустимые значения |
| :--- | :--- | :--- | :--- |
| `title` | строка (string) | Да | Заголовок темы. Длина: от 3 до 255 символов. |
| `content` | текст (text) | Да | Текст первого сообщения в создаваемой теме (тело темы). Не должно быть пустым. |
| `csrf_token` | строка (string) | Да | Токен защиты от CSRF-атак (генерируется автоматически сессией Flask-WTF). |

### 2.3. Успешный результат
* **Код ответа:** `302 Found` (редирект).
* **Поведение системы:** Данные проходят валидацию, в базе данных создаются записи в таблицах `topics` и `posts`, после чего происходит перенаправление пользователя на страницу созданной темы (`/topic/<slug>-<id>`).

### 2.4. Обработка ошибок (Характерная ошибка)
* **Тип ошибки:** Ошибка валидации данных (например, пустой заголовок темы `title` или `content`).
* **Код ответа:** `200 OK` (возврат шаблона формы с текстом ошибок) или `400 Bad Request` при нарушении целостности.
* **Поведение системы:** Тема не создается в базе данных. Пользователю возвращается HTML-страница формы создания темы с отображением сообщения об ошибке валидации под соответствующим полем (например: *«This field is required»* или *«Length must be between 3 and 255 symbols»*).

## 3. Примеры вызовов

### Пример 1. Успешный вызов (Создание темы)
* **Запрос:**
  * **URL:** `POST /forum/1/topic/new`
  * **Тело запроса:**
    ```text
    title=Добро пожаловать на форум&content=Это первое тестовое обсуждение в новом разделе.&csrf_token=ImVj...
    ```
* **Ожидаемый результат:** 
  * Код ответа: `302 Found`
  * Заголовок ответа `Location: /topic/dobro-pozhalovat-na-forum-2`
  * В БД появляется новая запись в таблице `topics` с `forum_id = 1` и `title = "Добро пожаловать на форум"`, а также связанный `post`.

### Пример 2. Ошибка (Пустой заголовок темы)
* **Запрос:**
  * **URL:** `POST /forum/1/topic/new`
  * **Тело запроса:**
    ```text
    title=&content=Текст сообщения есть, а заголовок забыли указать.&csrf_token=ImVj...
    ```
* **Ожидаемый результат:**
  * Код ответа: `200 OK` (повторный показ формы).
  * В тексте ответа содержится сообщение об ошибке валидации для поля `title`: *«This field is required.»* или аналогичное ограничение длины.
  * Записи в базу данных не добавляются.
